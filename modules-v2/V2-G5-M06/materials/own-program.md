# MAT-05 - S3: Deine rechteckige Prüffahrt

Entwirf eine Prüffahrt. Sie beginnt bei (1,3) mit Blick nach rechts.
Besuche nacheinander (3,3), (3,2), (1,2) und (1,3).
Fahre nur am Rand dieses Rechtecks und blicke am Ende wieder nach rechts.
Nutze eine feste Wiederholung. Zeichne zuerst deine Anweisungen mit dem
ganzen Wiederholungskörper. Schreibe dann deinen Code. Sage einen Zustand
voraus und prüfe ihn an der Laufspur. Erkläre, warum deine Fahrt passt.

## P3a - Eigene Ablaufgrafik

Zeichne Start und Ende, alle Anweisungen in Reihenfolge, den vollständigen Körperrahmen und die Anzahl. Diese Grafik ist dein eigener Entwurf und wird nicht automatisch aus dem Code erzeugt.

## P3b - Tatsächlicher Code

Gib deinen Code selbst ein. Prüfe vor dem Lauf: Enthält der Körper ein bis fünf Grundanweisungen? Ist die Anzahl zwischen 2 und 9? Gibt es keine verschachtelte Wiederholung?

## P3c - Vorhersage und ausgewählte Spur

Wähle vor dem Ausführen einen Zustand aus, den du vorhersagst. Wähle nach dem Lauf nur die Schrittnummern aus, die deine Erklärung tragen. Der Beleg bleibt mit genau diesem Code verbunden.

## P3d - Kriteriencheck

- [ ] Prüfpunkte in der geforderten Reihenfolge besucht
- [ ] nur am Rand des Rechtecks gefahren
- [ ] Endort `(1,3)` und Blick nach rechts
- [ ] feste Wiederholung verwendet
- [ ] Grafik, tatsächlicher Code und ausgewählte Spur verglichen
- [ ] eine eigene Entscheidung begründet

Ein fehlerfreier Lauf genügt allein nicht. Gleichwertige, längere Randfahrten können passen, wenn alle Kriterien erfüllt sind.
