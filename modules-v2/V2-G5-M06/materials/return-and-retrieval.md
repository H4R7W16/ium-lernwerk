# MAT-07 - Rückkehr und Abruf

## Rückkehrkarte

Diese Karte hilft beim Weiterarbeiten. Sie enthält keine Bewertung und keine alte Lösung.

- **Bereich:** Auftrag / Dossier / Sicherung
- **Mein Stand:** ______________________________________________
- **Offener Punkt:** ___________________________________________
- **Meine nächste Handlung:** __________________________________

## P4 - Erst abrufen, dann nachsehen

Die Lehrkraft hält die frühere Lösung zunächst verdeckt.

1. Schreibe aus dem Gedächtnis einen kurzen Wiederholungskörper mit mindestens zwei Grundanweisungen.
2. Entfalte zwei vollständige Durchläufe.
3. Begründe einen Zustand nach einer ausgewählten Aktion.
4. Markiere eine Unsicherheit.

Erst nach diesem eigenen Abruf folgt Rückmeldung und bei Bedarf die alte Lösung oder eine neue Erklärung. Eine wiederhergestellte Datei ist kein Abrufnachweis. Liegen die Termine direkt hintereinander, zeigt die Aufgabe nur unmittelbare Anwendung; ein späterer Abruf bleibt offen.

P4 wird nicht dauerhaft im Dossier gespeichert. Nur eine nötige nächste Handlung kann in die Rückkehrkarte übernommen werden.
